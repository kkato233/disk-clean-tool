# disk-clean-tool

ハードディスクを処分するときに、必要なファイルを残しながら、削除したファイルのデータが一般的な復元ツールで読み取られにくくなるようにすることを目指すツールです。

## 目的と仕組み

ファイルを削除しても、そのデータがディスク上にすぐ上書きされるとは限りません。本ツールでは、不要なファイルを削除したあと、対象ディスクの空き領域をゼロで埋めたファイルを書き込み、削除データが残っている領域を上書きすることを目指します。必要なファイルは削除せずに残します。

## 注意事項と制限

- 実行前に、必要なファイルのバックアップを取り、対象ディスクを十分に確認してください。誤ったディスクを対象にすると、必要なデータを失うおそれがあります。
- この方法は、一般的なデータ復元ツールによる削除ファイルの復元を防ぐことを目的としていますが、復元できないことを保証するものではありません。
- ディスクの分解や、記録媒体に残る微弱な磁気から上書き前の情報を読み取るような高度な解析への対策にはなりません。
- ファイルシステムやディスクの動作によっては、空き領域への書き込みだけでデータを完全に消去できない場合があります。重要な情報を確実に消去する必要がある場合は、ディスクメーカーや専門家が推奨する消去方法を確認してください。
